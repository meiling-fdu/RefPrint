## Overview

RefPrint studies **training-free synthetic image attribution** from a reference-based perspective.

Given a query image and reference images from candidate generators, attribution is performed by comparing their representations without training an additional classifier. We systematically investigate two key factors:

- **Representation selection:** which feature representations and layers are most suitable for source attribution?
- **Reference selection:** how should reference images be selected to provide reliable evidence for attribution?

Our experiments show that **intermediate representations** can outperform final-layer features, while **semantically aligned references** substantially improve attribution performance.

### BC-Attr-6

BC-Attr-6 contains:

- **10 synthetic image generators**
- **6 semantic categories**
- **1,200 query images**
- **10,800 pre-generated reference images**
- **120,000 resynthesis reference images**

The released dataset also provides the exact reference-selection protocols used in the paper:

- arbitrary references
- semantically aligned references
- resynthesis references

Please refer to the [BC-Attr-6 dataset card](https://huggingface.co/datasets/Meilinger00/BC-Attr-6) for the complete data structure and usage instructions.

## Method

RefPrint performs source attribution by comparing the representation of a query image with reference images generated by candidate sources.

The framework supports different:

- visual encoders and representation layers;
- reference-selection strategies;
- reference budgets.

A detailed implementation and reproduction instructions will be released in this repository.
